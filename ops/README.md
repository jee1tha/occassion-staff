# Growth desk

The local web app for the Occasion growth agents: approvals, vendor knowledge base, agents and evals,
models, and ROI. See the [repo README](../README.md) for how to run it and what each page is for.

```sh
cp .env.example .env.local
npm install
npm run dev -- -p 3100      # http://localhost:3100
```

No login: keep it local.
